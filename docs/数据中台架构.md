# 云枢 DataHub · 数据中台架构（Phase 0）

> 控制面生长在 Axis 上；执行面（采集/湖仓/查询）后续再接入。  
> 详细路线图见对话中的 DataHub 画布。

## 边界

| 层 | Phase 0 | 后续 |
| --- | --- | --- |
| 控制面元数据 | `dh_source` / `dh_dataset` / `dh_ingest_job` / `dh_ingest_run` | 血缘、质量规则、服务目录 |
| 控制面库 | PostgreSQL（与 Axis 同一套） | 仍不做数仓 |
| 执行面 | 手动触发采集：源端受控读取 + `dh_ingest_run` 指标（批大小受 `DataHub:DefaultBatchSize` 约束，暂不落 ODS） | U8 只读 DiffDetect → ODS |
| 流批/实时 | 延后 | Kafka / Flink / OpenMetadata |

## 模块映射

- **数据源** `DhSource`：类型、密钥引用（不落明文连接串）、只读标记
- **数据集** `DhDataset`：对象类型、对象名/自定义 SQL、主键与增量字段、更新策略
- **采集任务** `DhIngestJob`：策略、Cron、批大小
- **采集运行** `DhIngestRun`：运行状态、水位线、读写行数、错误信息

权限码：`datahub:{source|dataset|ingest-job|ingest-run}:{query|create|edit|delete}`；采集任务另含 `datahub:ingest-job:run`（立即执行）。  
配置：`src/Axis.Host.Api/Config/14-DataHub.json`。

## 采集执行（Phase 1 MVP）

- API：`POST /datahub/ingest-job/{id}/run`，权限 `datahub:ingest-job:run`
- 执行器经 `SourceConnectionFactory` 解析 `SecretRef` / 连接串，对任务关联的数据集做 COUNT + 限量 `SELECT`（不写 ODS，`RowCountChanged` 为 0）
- 增量策略：沿用上次成功运行的 `Watermark`，对本批结果取增量字段最大值写回
- Cron 调度与 Kafka / 血缘仍不在本阶段

## 不做（本阶段）

- Cron 自动调度与湖仓落表  
- 流式管道、元数据平台对接  
- 明文密钥入库（`AllowPlaintextSecrets=false`）

## SecretRef 约定

数据源不存明文连接串。`SecretRef` 仅存引用：

| 前缀 | 含义 | 示例 |
| --- | --- | --- |
| `config:` | 应用配置键（appsettings / 配置中心） | `config:ConnectionStrings:U8Readonly` |
| `env:` | 环境变量名 | `env:DH_SOURCE_U8_READONLY` |
| （空） | 暂未配置，采集执行前需补齐 |  |

前端「连接密钥」区会引导选择来源并自动拼接；`AllowPlaintextSecrets=false` 时禁止把连接串写进库。

前端打开数据源表单时会请求 GET /datahub/source/secret-ref-options，动态列出配置键（不含明文）。
